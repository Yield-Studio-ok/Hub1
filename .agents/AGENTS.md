# Project Rules: Yield Studio

## Orchestration & Subagents

- Do not assign fullstack subagents unless the task specifically requires touching BOTH frontend and backend simultaneously. Keep subagent roles specialized (e.g., frontend-only or backend-only) whenever possible.

## Testing & Methodology

- Strictly follow TDD (Test-Driven Development). Write tests before implementing features. Ensure comprehensive test coverage for all new code.
